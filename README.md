# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.




--------------------------------------------------------------------------------------------------------------------

1. Create a project using vite - npm create vite@latest
2. clear all unwanted styles from index.css & app.css
3. clear unwanted codes from App.jsx
4. Integrate Material UI(MUI) -  npm install @mui/material @emotion/react @emotion/styled
5. Install react icon -- npm install react-icons --save
